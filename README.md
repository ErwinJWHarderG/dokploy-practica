# Aplicación de prueba para Dokploy

Aplicación Node.js con Express creada para la práctica de Administración de Infraestructura de TI de la Universidad del Quindío.

## Tecnologías
- Node.js
- Express
- Docker
- Dokploy

## Rutas
- `/`: muestra información de la aplicación.
- `/health`: permite comprobar su estado de funcionamiento.

## Ejecución local
1. Instalar las dependencias con `npm install`.
2. Iniciar la aplicación con `npm start`.
3. Abrir `http://localhost:3000`.
